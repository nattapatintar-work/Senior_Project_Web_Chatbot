**Batch B (5 recipes)** — 7 desserts + 3 gap-filling savory dishes resolving the 5
ingredients still uncovered after Batch A: `rambutan`, `tamarind`, `chayote`, `spaghetti`,
`hyacinth_bean`. 4 of 5 resolved cleanly; `hyacinth_bean` took real back-and-forth:

1. First attempt used USDA's **mature-seed** hyacinth bean record (FDC 175210, dried
   beans, 344 kcal) — wrong food form for the dictionary's fresh-pod vegetable entry.
2. User asked to specifically check **IFCT 2017** (Indian Food Composition Tables,
   ICMR-NIN) before accepting the gap as unresolved, since hyacinth bean pods are a common
   Indian vegetable. Checked the official `ifct2017/ifct2017` GitHub mirror directly:
   found 3 "Field bean" entries (B007/008/009), but all three are **also** the dried
   mature-seed form (~275-285 kcal) — same wrong food form, not a match.
3. Re-searched USDA more broadly and found the record that had been missed the first
   time: **FDC 169234, "Hyacinth-beans, immature seeds, raw"** — the actual fresh pod, 46
   kcal/100g, which independently cross-checks against unrelated secondary sources quoting
   the same figure.
4. User asked for exact source/ID/value confirmation before proceeding, given the
   contradiction with the first report — provided a side-by-side table (175210 vs 169234)
   before writing anything.

All three USDA-sourced dishes (chayote, spaghetti, hyacinth bean) apply the same
available-carbohydrate correction established for `th_040`'s broccoli: USDA's
carbohydrate-by-difference includes fiber, Thai FCD's `CHOAVLDF` excludes it, so each
stores `by-difference minus fiber` with both raw numbers kept in
`external_nutrition.json` for the subtraction to stay checkable.
